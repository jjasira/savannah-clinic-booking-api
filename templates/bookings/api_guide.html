Developer reference

Booking API guide

Use timezone-aware ISO-8601 timestamps. All appointments must fall on a doctor's configured working day, within working hours, on a 30-minute boundary, and at least one hour in the future.

POST
/appointments

Book a time slot. Send doctor, patient, and starts_at in JSON.

GET
/doctors/{id}/availability?date=YYYY-MM-DD

Returns all currently available 30-minute slots for the doctor.

PATCH
/appointments/{id}/cancel

Cancel an appointment with a JSON reason. The slot becomes available again.

PATCH
/appointments/{id}/reschedule

Move a booked appointment using JSON starts_at.

GET
/patients/{id}/appointments

Returns a patient's upcoming active appointments.
